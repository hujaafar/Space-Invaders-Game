## Orbital artwork

`images/orbital.jpg` was generated for this redesign on September 10, 2026, using OpenAI image generation. It is original concept art, not a photograph or historical space image. The 1536 × 1024 source was encoded as an optimized JPEG for the site.

Art direction: charcoal space; a large cratered moon with warm ivory rim light in the upper right; one interceptor with sage ion engines; subtle blue atmospheric haze; sparse stars and fragments; quiet dark space on the left for typography; no embedded text or interface.

## Fonts

- **Space Grotesk**, Latin variable subset (300–700), Florian Karsten. Retrieved from Google Fonts; SIL Open Font License, included in `fonts/SPACE-GROTESK-OFL.txt`.
- **IBM Plex Mono**, Latin regular subset, IBM. Retrieved from Google Fonts; SIL Open Font License, included in `fonts/IBM-PLEX-MONO-OFL.txt`.

Font binaries are served locally. No font CDN connection is required when the game runs.

## Audio

Current effects are synthesized at runtime with Web Audio oscillators. The new game does not download audio or start it automatically on a first visit.
